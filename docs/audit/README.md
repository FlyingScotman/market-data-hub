# Audits of 15 October 2026 (historical)

These audits describe the collectors and databases that existed **before** the hub was built
(`market-data-store`, `moex-market-data-mcp` and the owner's other repositories), the
requirements of 15 October 2026 and the connectivity tests of that day. They are the input
the hub's design started from ([DESIGN.md](../DESIGN.md)) and are kept as history: they are not
updated, and their findings about the old systems do not describe the hub.

Open work is tracked in
[GitHub Issues](https://github.com/FlyingScotman/market-data-hub/issues); the current state of
the hub is in [SYSTEM_CONTEXT.md](../SYSTEM_CONTEXT.md).
